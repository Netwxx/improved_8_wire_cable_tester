# improved_8_wire_cable_tester

Improved 8-wire cable tester with an Arduino Nano (designed for SPI cable, but applicable to more) that tests (with data) forwards and backward, and with a Walsh-Hadamard Parallel Test.

Serial output of arduino is diabled, due to pin D0 being used, connect an I2C LCD display via the designated I2C pins.

Simple wiring diagram included, with KiCad and PDF.
